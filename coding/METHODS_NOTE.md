# Methods note: the coding procedure as executed

Every sentence here is true of what was done. The paper's method section is written from it.

**Corpus.** 52 manifest rows: 43 labelled framework versions and silent same-label variants across 12 providers, plus 9 companion documents. Every retrieved file is SHA-256 hashed with retrieval provenance (34 from providers, 14 from the Internet Archive, 1 manual download).

**Tracing and first-pass coding.** For each of twelve version pairs, commitments in the earlier version were listed from a recall-oriented sentence extraction, filtered by the codebook's inclusion rules, and traced into the later version; additions were detected in the reverse direction. First-pass coding of outcome, materiality and announcement status was performed with language-model assistance under codebook version 0.1, producing 710 rows with verbatim text on both sides, a stated rationale and a confidence grade. Every quoted field was mechanically verified against the corpus text (2,130 checks; 23 fuzzy matches at page breaks, flagged). Version 0.2, frozen the next day, settled six questions the first pass raised and introduced the partial-announcement code ANN-P.

**Adjudication.** 244 rows were adjudicated individually: all 50 units of the second-coder sample, every row affected by a post-first-pass codebook decision (present-tense rule, enumeration rule, MIX flag, partial-announcement code, provider-account definition, companion-document rule) and every low-confidence material row. Adjudication used the paired passages, the first-pass rationale and the provider's revision account, and applied the codebook, not the first-pass code. The remaining 466 rows were accepted after a random spot-check of 45 (one change). Adjudication changed 4 outcome codes and 56 announcement codes, 46 of them from SIL to ANN-P.

**Re-runs.** The first pass was re-run three times on all 710 rows under version 0.2 with the same model and task text (`reruns/run_log.csv` records model, settings and timing per track). Each run received the original commitment list without codes. `reruns/checkA_summary.md` reports the agreement between runs and against the adjudicated codes.

**Re-examination.** Every row on which any run disagreed with an adjudicated code, 249 rows, was re-examined against the two texts, the account and the codebook under four readings fixed in advance: a class-level mention counts only when the class is locatable in the document; a located class with a stated direction that applies is ANN, otherwise ANN-P; a commitment that leaves the framework and survives in a companion in the corpus or in a non-binding recommendations section is L; enumerations follow rule 11.2 as written. The decision and reason for each row are in `READJ_*` and `READJ_notes`.

**Blind re-coding and review.** Fresh model instances, in twelve groups, re-coded the 249 rows with the documents, the account and the fixed readings (`blind_recoding/RULES.md`) and no code. Their codes are in the `BLIND_*` columns. Each of the 92 rows carrying a disagreement was adjudicated against the texts (`blind_recoding/review_decisions.csv`); 37 rows changed, and each change is written into the `READJ_*` columns and logged in `READJ_notes` and `REVIEW_notes` with the code it replaced. `REVIEW_decision` marks every row as not re-examined, agreed, disagreed and kept, or disagreed and changed.

**Second coding.** Two model coders of a different model family each received the coder package alone (`second_coder_package/`: the 50-unit sample, instructions, a standalone codebook and the revision accounts) and returned the sheets in `second_coder_returns/`. One unit (U50, MSFT-1-001) carried a duplicated quotation in the package as first issued; both coders recoded it from the corrected texts, and the package here carries the corrected texts.

**Agreement.** `analysis/compute_agreement.py` reports Krippendorff's alpha (nominal, bootstrap 95% interval) for each decision separately, on all rows and on the rows where the three-way announcement choice arises. No human coded independently of the authors.

**Metrics.** Silent revision rate = material changes not identifiable in the provider's revision account / all material changes, computed over the eight pairs with a revision account. Strict counts ANN-P as silent; lenient counts it as announced. xAI's four pairs have no revision account and are reported by direction only. Silent same-label re-uploads (nine) are reported as a separate table.

**Limitations to state.** (1) Coding is interpretive and all reliability evidence is model-based. (2) Naver's 2024 version exists only as an English summary web page, so NAV-1 over-counts additions. (3) Anthropic's Frontier Compliance Framework versions contemporaneous with RSP v3.0 are no longer publicly retained; relocation was checked against FCF v2 (July 2026) with the temporal caveat flagged. (4) Internet Archive rate limiting prevented some neighbour-capture checks. (5) The rule that a located class with a stated direction counts as announced is a judgement call; ANN-P and the two thresholds make its effect visible, and the second coders divide on exactly that boundary.
